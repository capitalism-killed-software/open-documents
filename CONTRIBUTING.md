# Contributing

Thanks for helping. A few rules keep this project safe to embed.

## Setup

Node 24 or newer.

```sh
npm ci
npm run check   # lint, licence check, tests with coverage
```

## Rules

- **Tests first.** Write the failing test, then the code. Coverage gates are in `package.json`.
- **No real documents.** Tests use files generated by `@open-documents/fixtures`, so every test
  knows exactly what is inside. Never commit a PDF, DOCX or scan from anywhere else, even a
  public one.
- **Licences.** Read `docs/licensing.md` before adding a dependency. AGPL and GPL tools are out,
  whatever they are wrapped in.
- **Plain JavaScript.** ES modules, JSDoc for types. No build step for the library itself.
- **Small commits** that each do one thing, with a short message about the change.

## Reporting a security problem

Please do not open a public issue. See `SECURITY.md`.
