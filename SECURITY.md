# Security

Open Documents reads files from people you do not know. If you find a way to make it crash,
hang, use unbounded memory, read or write files it should not, reach the network, or leak
content that was meant to be removed, please tell us privately.

## How to report

Use GitHub's private reporting: the **Security** tab of this repository, then
**Report a vulnerability**. Include a way to reproduce it. If a file is needed, please build it
from code (see `packages/fixtures`) or strip it of anything personal first.

We aim to reply within a week and to fix serious problems before talking about them in public.

## Supported versions

Until 1.0, only the latest release gets fixes.
